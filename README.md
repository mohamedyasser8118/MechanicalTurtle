# Mechanical Turtle

A C++ console application that simulates a mechanical turtle drawing on a 50×50 grid floor using simple numeric commands.

## Commands

| Command | Description |
| :--- | :--- |
| `1` | Pen up |
| `2` | Pen down |
| `3` | Turn right |
| `4` | Turn left |
| `5 <n>` | Move forward `n` spaces (e.g. `5 12`) |
| `6` | Print the 50×50 floor |
| `7` | Clean the floor and reset position |
| `9` | Exit program |

## Build & Run

```bash
g++ Mechanical_Turtle.cpp -o Mechanical_Turtle
./Mechanical_Turtle
```
